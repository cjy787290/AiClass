# 內容資料夾說明

## 首頁素材

- `home/photos/`：三張入口圖片與圖釘素材。實際使用的圖片路徑在根目錄的 `index.html`。
- `home/background/`：首頁背景素材。目前使用 `魔法科技風_軟木塞.svg`，路徑設定在 `src/styles.css` 的 `.cork-board`。

## 三個主題的頁面

- `文字魔法變簡報/pages/`：第一個主題。
- `圖文玩出簡報力/pages/`：第二個主題。
- `實用工具百寶箱/pages/`：第三個主題。

每個主題的入口都放在對應的 `pages/` 資料夾內。目前「文字魔法變簡報」使用 `DEMO1-文字做投影片-精簡排版.html`，「圖文玩出簡報力」使用 `圖文描述製作投影片_互動網頁.html`，而「實用工具百寶箱」使用 `index.html`。更換網頁時，可沿用該主題目前的入口檔名並取代檔案；若要使用其他檔名，請同步修改 `src/main.js` 中該主題的 `entry`。不必為每一頁建立 `page-01`、`page-02` 等資料夾；頁面內的換頁、連結及互動由你放入的網頁自行提供。

若網頁依賴其他 HTML、CSS、JavaScript、圖片或素材資料夾，請一併放入 `pages/`，並保留網頁原本使用的相對路徑。支援可直接由瀏覽器載入的靜態網頁；需要伺服器程式或資料庫的功能須另行配置。完成後執行 `pnpm build` 和 `pnpm preview`，確認各頁、素材和連結正常。

前兩個主題已接上新的互動網頁；「實用工具百寶箱」的 `index.html` 仍是暫用入口，連接原有的兩份工程資訊課程網頁。
