課程精華

核心概念

依 D1 下午、D2 上午、D2 下午筆記重整

思維突破 01

放鬆學 AI，把角色切成導演與執行者

課程強調 AI 沒有固定規則，關鍵在使用者的創意、問題拆解與導演能力。使用者負責定義目標與檢查成果，AI 則協助寫程式、整理資料、製圖、剪輯或產出報告。

多工協作 02

同時調度多個 AI 工具

不要等待單一工具完成所有任務；可同時開啟 ChatGPT、Gemini、Codex、Claude 等工具，分別負責架構討論、程式生成、除錯、文件整理與交叉驗證。

資安邊界 03

地端、雲端與企業資料的界線

核心 Know-how 若放到公開雲端模型，可能有資料外流或被訓練的風險；若追求絕對資安，需考量地端部署與硬體成本。正式商用系統則應放到企業級雲端環境並納入權限控管。

資料信任 04

NotebookLM 與 RAG 適合精準查核

NotebookLM 適合依據使用者餵入的文件回答，並標註引用來源，對工程合約、採購文件、消防法規與長篇規章追蹤特別有價值。

工具階級 05

初階、中階、高階工具分工

課程將工具分為 Gemini 網頁版與 Canvas、Google AI Studio 的雲端開發，以及 AntiGravity 類地端環境。現階段重點不是成為全端工程師，而是用自然語言調用既有資源。

雲地混合 06

避免過度依賴單一雲端 API

長期依賴雲端 API 可能面臨額度調整、費用或斷線風險。雲地混合能保留基本生產力，也能讓內部資料與模型使用更可控。

實作導向

業務痛點與 AI 應用

整理自分組討論與講師示範

地圖服務

特約商店清冊轉互動式地圖

將福利會清冊結合 GPS 定位，讓使用者以「肚子餓、想找燒烤店」這類自然語言查詢周邊簽約商店，並可避開付費地圖 API，改找開源地圖方案。

文件審查

招標與履約文件雙專家比對

以多角色審查方式比對履約文件，共同點可直接留存，差異點再由人工覆核責任歸屬，用於降低大型文件人工審閱負擔。

資安通報

漏洞公告比對內部資產

AI 可定時收集政府與資安網站公告，與內部資產清冊比對後產出通知信，協助縮短漏洞曝露時間；但資安判斷仍需專業人員把關。

工程圖資

CAD/BIM 參數比 PDF 更適合 AI 判讀

大型開挖數量、管道米數或工程項目若只靠 PDF 平面圖，AI 難以精準判讀；應提供 CAD 原始檔或 BIM 模型，並搭配進度照片與表單格式自動產出月報、週報與簡報。

發票辨識

OCR 轉數據並回填試算表

透過 Google AI Studio 連結企業雲端硬碟與試算表，讓前台支援拍照，後台解析發票數字，並依公式自動回填到 Google 試算表。

成果發表

用動態錄影取代繁重排版

課堂成果可用 Windows 小剪取工具錄製作品操作，再將與 AI 的對話過程、最優提示詞、單位與姓名整理到 Google 文件，不需花大量時間重排版。

質性回饋

學員回饋與行動策略

Keep

最受肯定的設計

  • ✓講師展示戰情中心、Sensor 與維護管理系統等工程結合案例。
  • ✓透過 Codex 快速排除環境建置問題，降低寫程式門檻。
  • ✓講師導讀後讓學員自選題目實作，現場可即問即答，做中學效率高。
Pain Points

下期應優先改善

  • 公司網路安裝 Codex 速度過慢，影響課程開場節奏。
  • 資訊量密集，非資訊背景同仁需要更多術語導讀與消化時間。
  • 免費版 Codex、Notion AI 或 API 額度很快用完，影響課後延伸落地。
短期行動

場地網路與課前準備

下期課程前，資訊處可針對 GitHub、大型開源模型與 AI 工具建置所需通訊埠進行外網下載測試，並提供課前環境建置指南與白話術語對照表。

中長期策略

分階學程與企業級授權

可規劃初階戰略班、進階工具實作班、專案落地工作坊，並評估企業版 AI 工具、內部算力與模型 API 額度，避免課後因工具費用中斷推廣。
