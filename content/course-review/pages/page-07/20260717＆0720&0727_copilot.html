課程內容整理

Microsoft 365 Copilot 實作 Workshop

本次課程以「Microsoft 365 Copilot 實作 Workshop」為主題，帶領學員從 Copilot 的基本概念、授權差異、操作入口與介面導覽開始，逐步進入 PowerPoint、Excel、Word 與 Agent Builder 的實作情境。課程核心不是只介紹 AI 工具功能，而是讓學員理解如何把 Copilot 放進日常 Office 工作流程，協助整理資料、產生初稿、比對文件、檢核表格與建立可重複使用的部門作業模式。

講師在開場強調，AI 與傳統系統是兩種不同的做事方式。系統適合規則固定、輸入輸出明確、每次都要高度一致的流程；生成式 AI 則適合彈性理解、重點整理、初稿生成與提供不同角度。AI 的輸出不一定每次完全相同，因此適合用在人機協作，而不是完全取代人工檢核。實際導入時，需要依照工作情境的標準化程度與自動化程度，判斷該使用 M365 Copilot、Copilot in App、Agent Builder、Copilot Studio、Power Automate 或其他進階架構。

課程目標

  • 建立對 Microsoft 365 Copilot 的基礎認識，理解它如何結合大語言模型、Microsoft Graph、工作資料、Office Apps、網路資料與企業資料保護。
  • 認識 Copilot Chat 與 M365 Copilot 的差異，特別是基本授權與進階授權在資料讀取、Office 文件操作、多步驟任務與 Agent 應用上的差別。
  • 熟悉 Copilot 的常用入口，包括瀏覽器 m365.cloud.microsoft、M365 Copilot Desktop App，以及 Teams 左側的 Copilot。
  • 透過六個 Hands-on Lab，把 Copilot 應用在簡報製作、Excel 資料清洗分析、簡報精修、預算 SOP 檢核、文件比對更新與 Agent 產生簽呈。
  • 理解 Prompt、SOP Prompt、Skill 與 Agent 的關係，並知道如何把個人經驗整理成可共享、可測試、可調整的工作流程。

Microsoft 365 Copilot 介紹

Microsoft 365 Copilot 是結合自然語言、大語言模型、Microsoft Graph、工作相關資料、Microsoft 365 Apps、Web，以及 Microsoft Security & Compliance 的工作助理。講師說明，Copilot 不只是單次問答工具，而是可以讀取使用者授權範圍內的工作脈絡，例如郵件、行事曆、Teams、SharePoint、OneDrive 與近期開啟的文件，進一步協助完成文件與協作任務。

課程中也提醒學員要使用公司帳號登入，確認畫面上有企業資料保護相關標示。使用企業帳號時，工作資料會受到企業級保護，不會像一般消費者服務一樣被任意拿去訓練模型。這一點對公司內部文件、會議紀錄、預算資料與契約文件尤其重要。

近半年 Copilot 的更新方向，已經從「換新模型」與「在 Office 裡使用」逐漸走向 Agent 流程與系統連接。例如 Copilot in App 編輯模式、Word / Excel 的 agentic editing、Copilot Cowork、Agent Flow、Copilot Studio 與 MCP 等方向，都顯示 Copilot 正從單一工具升級為可以協助推進流程的執行夥伴。

Copilot Chat 與 M365 Copilot 的差異

基本版 Copilot Chat 偏向單次對話與單次回答，通常需要使用者自行複製貼上結果，再回到文件中處理。它主要依賴公開網路資料，無法完整讀取郵件、行事曆或內部檔案，也缺乏組織工作脈絡。

M365 Copilot 進階授權則可以處理較複雜的多步驟任務，並透過 Work IQ 整合郵件、行事曆、Teams、SharePoint、OneDrive 等工作資料。它也能在 Office 文件中直接協助編輯，讓使用者把重複性的文件作業、資料整理與初稿產出放進既有工作流程。

講師建議，若是單純問問題，可以從 Chat 開始；若是要產生或編輯文件、簡報、Excel 分析結果，則應回到 Office App 或瀏覽器版本中開啟檔案，再使用 Copilot 進行操作，穩定性會更高，也更容易人工檢核。

操作入口與介面重點

課程介紹三種常用入口。第一種是從瀏覽器進入 m365.cloud.microsoft，使用公司帳號登入。第二種是下載並使用 M365 Copilot Desktop App。第三種是在 Teams 左側功能列點選 Copilot 圖示。講師建議以瀏覽器與 Desktop App 為主要入口，Teams 入口適合快速詢問，但部分功能可能比較受限。

在 Copilot Chat 介面中，學員需要注意 Work IQ 是否開啟。關閉時較偏向搜尋 Web 資料；開啟時則會讀取 Microsoft 365 工作資料，例如信件、會議、OneDrive 與 SharePoint 文件。介面也可以選擇不同模型，當自動模式無法符合預期時，可以嘗試切換模型，例如在較複雜的 Excel 分析情境中改用 Claude 類模型，或在簡報與影像生成情境中選用適合的模型。

Lab 1 多模態資料來源建立成簡報

第一個實作情境是用 Copilot PowerPoint Agent 從多種素材建立「高雄港 2026 上半年營運實績報告」簡報。提供的資料包含營運實績數據 Excel、營運摘要 Word、2025 年度回顧 PDF、營運會議重點 txt，以及港區作業照片。

操作流程分成三步。第一步先把多模態資料提供給 Copilot，請它規劃簡報大綱與各頁內容。第二步與 Copilot 討論，對焦簡報想法、頁面結構與重點。第三步在想法確認後呼叫 PowerPoint Agent，要求它建立簡報、補齊內容、插入照片、配置數據頁並統一風格。

這個 Lab 的重點是讓學員體會「從零到有」的文件生成流程。講師提醒，若只是想建立全新簡報或企劃書，可以從 Copilot 對話與 Agent 開始；但若要修改既有 Office 檔案，建議直接開啟該檔案後，在 Office 裡用 Copilot 編輯，結果通常會更穩。

可延伸應用的場景包括港口營運實績統計與圖文報告、月報或季報一鍵成簡報、工程進度與預算簡報更新、教育訓練教材、AI 擴充案計畫書、對外招商簡報、記者會簡報、公益活動企劃書與專案結案報告。

Lab 2 季度航線櫃量整併與多維分析

第二個實作情境是使用 Copilot in Excel 整理季度航線櫃量資料。原始資料來自各航商回報的櫃量明細，格式混亂，包含航商名稱寫法不一致、月份格式混用、空白、重複、小計列與疑似錯誤數值。目標是請 Copilot 協助整併、標準化、清洗資料，再進行多維分析與目標達成率檢查。

Lab 流程包含整併標準化、清洗與標示異常，再進一步產出多維樞紐、重空比例、YoY、達成率、異常提醒、長條圖與摘要。講師也特別指出，在 Excel 中使用 Copilot 的好處是它會保留公式，使用者可以檢查關鍵公式是否正確；相較於只把資料丟給 AI 產出一份答案，在 Excel 內編輯更容易追蹤與人工複核。

這個 Lab 延伸出許多資料處理場景，包括各航商航線櫃量增減分析、各港航線櫃量交叉分析、KPI 月報自動化、預算執行分析、損益分析報告、能耗與碳排統計、每月裝卸報表自動化、客訴與報修統計分析，以及處內人力盤點月報。

Lab 3 營運簡報改成業務會報版

第三個實作情境承接 Lab 1 的營運實績簡報，要求 Copilot in PowerPoint 將原本較完整的簡報改成業務會報用的五分鐘版本。任務包含精簡篇幅、補上講者備忘稿、統一整份風格，讓長官能快速掌握重點。

操作流程包含將簡報精簡為 6 到 7 頁、調整簡報規格、產生圖像化封面與封底、逐頁加入講者備忘稿。學員可根據自身需求要求 Copilot 改色系、改版型、產生封面封底圖像，或補充不同語氣的講稿。講師也提醒，若 Copilot 產出的內容已經完成七成到八成，剩下的細節可以由人手動微調，不一定每一步都要再下 prompt。

這個 Lab 可延伸到工程進度與預算簡報更新、同一份素材改成董事會版、員工版或記者會版、港口營運實績圖文報告、長簡報精簡成摘要、監造日誌品管分析，以及既有簡報改版翻新。

Lab 4 預算資料檢核與 SOP 稽核

第四個實作情境使用 Copilot in Excel 進行預算資料檢核。情境是依既定 SOP 稽核港務預算資料，例如歲出計畫提要與分支計畫概況表。資料看似表格，但實際上有許多非結構化描述，例如說明欄位一行一個儲存格、換行邏輯不固定、金額與科目不一定一對一對齊，需要透過語意判斷找出金額與說明是否對得上。

檢核任務包含擷取說明欄位中的金額、分配到正確的分支計畫、用途別與科別，檢查說明有金額卻未對應科目的情況，並檢查階層彙總是否正確。完成後，Copilot 需要標示問題、套用底色或註記，並產出可追溯的稽核摘要。

這個 Lab 也引入 SOP Prompt 與 Skill 的概念。講師把 Skill 說明成「給 Agent 看的 SOP」，也就是把常做工作的規則整理成可重複引用的指令與檔案，避免每次由不同人用不同說法描述，導致執行品質不一致。這個概念適合部門級流程，因為它需要經過測試與修正，直到輸出穩定可用。

延伸應用包括工程估驗計價審核、請款或核銷檢核、保全請款資料合規審查、報表交叉勾稽、品質查證表單扣款判定、規則型合規檢查、空白發票檢核，以及憑證與明細一致性檢查。

Lab 5 文件比對與更新

第五個實作情境使用 Copilot Chat 與 Copilot in Word 比對港區土地租賃契約的新舊版本。測試資料包含舊版契約與新版契約，新版中植入六處差異。任務是快速列出新增、修改與刪除內容，整理成對照表，標註每項差異對甲乙雙方的實質影響，並依主管指示更新文件。

課程示範兩種比對方式。第一種是在 Copilot Chat 中附上兩份文件，請 Copilot 比較差異並產生對照表。第二種是在 Word 中開啟新版文件，請 Copilot 參照舊版文件，直接在文中標紅或加註差異說明。若資料都在 OneDrive 或 SharePoint，可以透過 / 選取雲端檔案，降低版本混亂的風險。

講師也提醒，模型選擇會影響分析深度。若只是快速比較兩份文件，自動模式可能已足夠；若需要接近法務審查般的深入意見，可以嘗試深度思考或其他模型。最終仍要由承辦或負責人判斷內容是否正確。

延伸應用包括契約新舊版本比較、法規修正前後比對、契約對照表製作、SOP 或規範版本比對、採購招標文件比對與生成、報告版本追蹤、勞資會議提案單比對、投標文件與需求書勾稽，以及散雜貨報表交叉比對。

Lab 6 Agent 引導蒐集並套入 Word 簽呈範本

第六個實作情境結合 Agent Builder 與 Copilot in Word。情境是承辦收到來文後要辦理案件，但不確定簽呈應該怎麼寫。課程先用 Agent 一問一答引導承辦補齊資訊，再用 Copilot in Word 把整理後內容套入簽呈範本，形成正式草稿。

流程分成三段。第一段使用 Agent Builder 建立「簽呈小幫手」，讓 Agent 能根據承辦提供的案件背景、現況清單、各單位筆記或其他資料，引導使用者整理資訊並形成簽呈草稿。第二段使用 Prompt Coach 設計填寫 Word 簽呈範本的 SOP Prompt，將填寫邏輯變成可反覆使用的檔案。第三段實際測試，把案件背景資料交給 Agent 產生簽呈內容，再於 Word 開啟簽呈範本，提供簽呈草稿與 SOP Prompt，請 Copilot 依範本填入內容。

Agent Builder 的設定包含名稱、描述、指示、知識來源與可用能力。知識來源可以是檔案、SharePoint、OneDrive 資料夾、Teams 記錄或電子郵件。若選擇 OneDrive 資料夾作為知識來源，日後資料夾內容更新時，Agent 可讀取最新資料。講師也提醒，Agent 較適合引導、整理與生成內容；真正要對 Word、Excel、PowerPoint 進行細節編輯時，仍應回到 Office App 中操作。

這個 Lab 的價值在於把個人經驗轉成部門可共享的流程。當 Agent 與 SOP Prompt 經過多次測試後，可以設定分享範圍，提供給組織內任何人、特定使用者或特定單位使用。適合延伸到公文轉內部簽呈、引導式申請或表單、業務會報列管案件彙整、會議逐字稿成紀錄、立委關切案回應、報告初稿產生器、採購承辦方向與簽文初擬、制式文書自動填寫與公文分辦智慧助手。

進階場景分享

課程最後分享幾個進階應用方向。第一類是協助撰寫開標文件，由承辦提供相關文件，Copilot 整理開標文件所需資料，Agent 透過系統化提問把經驗式作業轉成可確認的資料收集流程，並整合廠商文件、會議紀錄與歷史案例。第二類是提供開標文件修改建議，依預先定義的審查規則檢視草稿，提出建議性審查意見，但最終內容仍由負責人員判斷。第三類是依範本完成採購公文草稿，將前面產出的資料與其他參考資料整理成公文初稿，提升撰寫效率。

課程也提到月報整理與寫入 Word 範本的場景，先整理 Excel 資料，再寫入 Word 文件。這與前面 Lab 2、Lab 4 和 Lab 6 的精神一致：資料處理、規則檢核、內容產生與範本套用可以串成一套工作流。

此外，M365 Copilot 內建多種 Prebuilt Agents。Researcher 適合深度研究，能跨網路與內部檔案彙整主題報告，也支援模型評議。Analyst 適合上傳 Excel 或 CSV 進行資料分析與圖表製作。Prompt Coach 則適合不知道怎麼寫 Prompt 或想優化 Prompt 時使用。

使用 Copilot 的工作原則

  • 先判斷任務屬於低標準化、高標準化、低自動化或高自動化，再選擇適合的 Copilot 工具與操作方式。
  • 建立新文件或新簡報時，可以從 Copilot Chat 或 Agent 開始；編輯既有 Office 文件時，建議直接在 Word、Excel 或 PowerPoint 中使用 Copilot。
  • 使用企業資料時，務必以公司帳號登入，確認企業資料保護狀態。
  • 資料若放在 OneDrive 或 SharePoint，可直接引用雲端檔案，避免版本混亂。
  • Prompt 不應只停留在個人記事本，常用流程應逐步整理成 SOP Prompt、範本或 Agent。
  • Copilot 的產出應視為初稿、分析輔助或檢核建議，重要文件、數字、法規、契約與預算結果都需要人工複核。
  • 若模型輸出不符合期待，可以調整 Prompt、補充背景、改用不同模型，或回到 Office 檔案中逐段編輯。

課程總結

這場 Workshop 透過六個 Lab 展示 Copilot 如何把日常 Office 工作做得更快、更穩。從多模態素材建立簡報、Excel 整併分析、簡報精修改版、預算 SOP 檢核、文件比對更新，到 Agent 產生簽呈，課程將「素材到成果」串成完整工作流。

真正的導入重點不只是會下 Prompt，而是能把常見工作拆成可描述、可檢查、可重複的流程。當個人使用經驗逐步被整理成 SOP Prompt、Skill 或 Agent，Copilot 才能從個人生產力工具延伸成部門協作與知識流加速工具。所有 Copilot 與 Agent 產出仍需人工複核，雲端共編與知識來源也應依資料敏感度分級處理。

二、 質性分析

1. 正面常見意見（最滿意或驚豔的部分）

實用性極高且貼近業務：學員特別讚賞課程中結合 Word 及 Excel 的 AI 實戰操作，能直接協助文件擬定，並了解微軟 AI 在預算編列審核上的應用。

貼心的行政服務：學員特別提到現場提供飲料與點心，讓人感到十分貼心。
